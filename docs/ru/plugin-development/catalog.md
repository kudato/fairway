# fairway-catalog

Каталог хранит данные по строковым адресам в памяти на время работы fairway.
Содержимое записи — произвольные байты. Потребитель определяет их формат
и смысл адреса, а каталог отвечает за сжатие, хранение и распаковку.

Начальное содержимое можно подготовить при сборке и встроить в программу —
это builtin. Во время работы записи можно добавлять и заменять.
Все операции синхронные.

Зависимости плагина:

```toml
[dependencies]
fairway-catalog.workspace = true
```

## Быстрый старт

```rust
use fairway_catalog::{Error, get, initialize, put};

fn main() -> Result<(), Error> {
    initialize()?;
    put("skill/git/commit", b"Commit instructions")?;

    assert_eq!(
        get("skill/git/commit")?,
        Some(b"Commit instructions".to_vec()),
    );
    Ok(())
}
```

Fairway вызывает `initialize()` перед первым обращением к каталогу.
Функция собирает builtin-записи подключённых крейтов в единый изменяемый
каталог. Если builtin-записей нет, каталог создаётся пустым.

При инициализации каталог сохраняет ссылки на встроенные сжатые данные.
Повторный `initialize()` после успешной инициализации сохраняет текущее состояние,
включая изменения, внесённые через `put`.

## Встроенные записи

В крейте, который поставляет builtin, добавьте зависимость для скрипта сборки:

```toml
[build-dependencies]
fairway-catalog = { workspace = true, features = ["build"] }
```

Feature `build` включает функцию `build` и тип `BuildError`.
В `build.rs` потребитель читает исходные файлы и назначает им полные адреса:

```rust
fn main() -> Result<(), Box<dyn std::error::Error>> {
    println!("cargo:rerun-if-changed=documents/commit.md");
    println!("cargo:rerun-if-changed=documents/convention.md");

    fairway_catalog::build([
        (
            "skill/git/commit".to_owned(),
            std::fs::read("documents/commit.md")?,
        ),
        (
            "resource/git/convention".to_owned(),
            std::fs::read("documents/convention.md")?,
        ),
    ])?;
    Ok(())
}
```

В `src/lib.rs` того же крейта один раз вызовите:

```rust
fairway_catalog::embed!();
```

## Адреса и содержимое

Адреса сравниваются буквально, с учётом регистра и без нормализации.
Смысл частей `skill/git/commit` и `resource/git/convention` задаёт
потребитель. Для каталога это строковые ключи.

Преобразование текстов, структур и других значений в байты и обратно
выполняет потребитель, например с помощью [fairway-codec](codec.md).

## Чтение и изменение

`get(address)` возвращает `Result<Option<Vec<u8>>, Error>`: исходные
распакованные байты или `None`, если адрес отсутствует. Полученный буфер
принадлежит вызывающему коду. Последующие изменения записи не меняют
уже полученные данные.

`put(address, content)` принимает адрес `&str` и содержимое `&[u8]`.
Он сжимает данные и добавляет запись либо целиком заменяет существующую,
в том числе builtin-запись.

Каталог доступен из нескольких потоков. Замена атомарна: одновременный
`get` получает целиком прежнее или новое содержимое. Ошибка `put`
сохраняет прежнюю запись.

Изменения хранятся только в памяти. При следующем запуске каталог снова
начинает с builtin; дополнительное наполнение выполняют потребители.

## Выборка адресов

`list(pattern)` возвращает `Result<Vec<String>, Error>` — снимок
подходящих адресов в лексикографическом порядке.
Если совпадений нет, список пуст.

Маска сопоставляется с полным адресом с учётом регистра.
`*` означает любую последовательность символов, включая пустую
и содержащую `/`. Остальные символы сопоставляются буквально.

| Вызов | Какие адреса выбирает |
|---|---|
| `list("*")` | Все адреса |
| `list("skill/*")` | Начинающиеся с `skill/`, например `skill/git/commit` |
| `list("skill/git/*")` | Начинающиеся с `skill/git/`, включая `skill/git/hooks/pre-commit` |
| `list("*/git")` | Заканчивающиеся на `/git`, например `skill/git` |
| `list("*/git/*")` | Содержащие `/git/`, например `skill/git/commit` и `resource/git/convention` |

`list("*/git")` не выбирает `skill/git/commit`: этот адрес не
заканчивается на `/git`.

## Ошибки

`build` возвращает `fairway_catalog::BuildError`, если отсутствует
`OUT_DIR`, произошла ошибка сжатия или записи артефактов.

`initialize`, `get`, `put` и `list` возвращают
`fairway_catalog::Error`. Для `get`, `put` и `list` требуется
успешная инициализация.

Повторяющиеся builtin-адреса приводят к ошибке `initialize`.
В сообщении указаны адрес и места обеих регистраций.
При таком конфликте каталог остаётся недоступным. Повторные вызовы
`initialize` возвращают ту же ошибку.

Ошибки сжатия и распаковки указывают адрес записи, а ошибки записи
артефактов — затронутый путь. Исходная ошибка, если она есть, доступна
через `std::error::Error::source()`. Оба типа ошибок реализуют
`std::error::Error + Send + Sync` и владеют своей диагностикой.
