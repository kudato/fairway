# Настройка Fairway

Fairway читает настройки ядра и плагинов из файлов TOML. В файле параметры
объединяются в таблицы с заголовками вида `[example]`.

Названия таблиц, допустимые параметры и значения по умолчанию описаны
в [руководствах соответствующих возможностей ядра](index.md) и в
[руководствах по плагинам](../plugin-guide/index.md).

## Каталог Fairway

Fairway ищет файлы настроек в `~/.fairway`. Каталог можно изменить, задав переменную окружения `FAIRWAY_HOME`. Если переменная задана, но пуста, Fairway не может определить каталог и сообщает об ошибке.

Если файлов настроек нет, Fairway использует значения по умолчанию для настроек ядра и плагинов.

```text
~/.fairway/
├── config.toml
├── config.auto.toml
└── conf.d/
    ├── 10-server.toml
    └── 90-local/
        └── example.toml
```

`config.toml` и `conf.d` — [файлы конфигурации](#файлы-конфигурации).

## Файлы конфигурации

Fairway читает:

- `config.toml` в каталоге Fairway;
- все файлы `*.toml` из его подкаталога `conf.d`, включая вложенные каталоги;
- `config.auto.toml` в каталоге Fairway.

Создавать файлы заранее не обязательно. Если `config.auto.toml` отсутствует,
Fairway создаёт его при загрузке настроек. В этом файле Fairway сохраняет
настройки, изменённые программно.

Если таблицы нет ни в одном файле, используются заданные для неё значения
по умолчанию.

Начните с `config.toml`. Каталог `conf.d` позволяет разделить настройки
на несколько файлов.

Fairway загружает настройки один раз при запуске, до начала работы.
Если изменить файлы настроек во время работы `fairway`, он продолжит
использовать ранее загруженные значения.

При запросе справки (`--help`), версии (`--version`) или ошибке
в аргументах Fairway завершается до загрузки настроек.

## Порядок файлов

Сначала Fairway читает `config.toml`, затем — файлы из `conf.d`
в лексикографическом порядке их путей, последним — `config.auto.toml`.
Значения из файлов, прочитанных позже, переопределяют ранее загруженные.
Таким образом, настройки из `config.auto.toml` имеют приоритет
над настройками из `config.toml` и `conf.d`.

Пути сравниваются по частям: сначала имена первого уровня внутри `conf.d`,
при совпадении — имена следующего уровня. Сравнение учитывает регистр,
а цифры в имени рассматривает как символы:

- `conf.d/A.toml` применяется раньше `conf.d/a.toml`;
- `conf.d/a/z.toml` применяется раньше `conf.d/b.toml`;
- `conf.d/10-base.toml` применяется раньше `conf.d/2-local.toml`.

Чтобы порядок был очевиден, начинайте имена с номера одинаковой длины:
`10-`, `50-`, `90-`.

## Объединение значений

Fairway объединяет таблицы с одним и тем же именем. Поздний файл меняет
только перечисленные в нём параметры, остальные сохраняются. Вложенные
таблицы объединяются по тому же правилу. Строки, числа и массивы
заменяются целиком.

`config.toml`:

```toml
[example]
listen = "127.0.0.1:8787"
idle_ttl = 300
```

`conf.d/10-server.toml`:

```toml
[example]
listen = "0.0.0.0:9000"
```

`conf.d/90-local/example.toml`:

```toml
[example]
idle_ttl = 60
```

Первый дополнительный файл меняет `listen`, второй — `idle_ttl`.
Если `config.auto.toml` не переопределяет эти параметры, в итоговой
таблице будут `listen = "0.0.0.0:9000"` и `idle_ttl = 60`.

- Типы и обязательные параметры проверяются после объединения файлов,
  поэтому каждый файл может задавать только часть параметров.
- Массивы, в том числе массивы таблиц `[[...]]`, заменяются целиком:
  элементы из разных файлов не складываются.
- Пустая таблица `[example]` в позднем файле не сбрасывает настройки.
  Чтобы изменить параметр, задайте новое значение. Чтобы убрать его
  из конфигурации, удалите его из всех файлов, где он указан.

## Какие файлы читаются

- В `conf.d` читаются файлы с расширением `.toml` в нижнем регистре.
  `README.md`, `10-server.toml.bak` и `20-server.TOML` пропускаются.
- Скрытые файлы и каталоги тоже читаются: `conf.d/.local.toml` применяется
  наравне с остальными.
- Символические ссылки на файлы и каталоги разрешаются, `conf.d` тоже может
  быть ссылкой. Битая ссылка внутри `conf.d` — ошибка, как и ссылка
  на родительский каталог, которая зацикливает обход.
- `config.toml` должен быть обычным файлом или ссылкой на обычный файл.

## Значения

- Строки передаются ядру и плагинам как есть: `~` и переменные окружения
  не раскрываются, относительные пути не привязываются к расположению
  файла.
- Таблицы верхнего уровня должны быть объявлены ядром или плагинами,
  включёнными в программу. Опечатка в имени, например `[exampel]` вместо
  `[example]`, приведёт к ошибке загрузки с указанием имени и файла.

## Ошибки

Перед выполнением работы Fairway проверяет все настройки ядра
и подключённых плагинов.

Если хотя бы одну таблицу загрузить не удалось, Fairway печатает ошибку
и завершается с кодом 1. Значения по умолчанию вместо ошибочных не
подставляются.
