# Использование Fairway

Fairway — CLI, команды в неё добавляют плагины собираемые вместе с Fairway,
поэтому набор команд зависит от того, какие плагины вошли в сборку.
Первое слово после `fairway` — имя пространства команд, дальше идут подкоманда,
если она есть, и аргументы:

```text
fairway <пространство> [подкоманда] [аргументы]
```

## Установка

Fairway публикуется на PyPI и crates.io. Запустить его без установки можно
через [uv](https://docs.astral.sh/uv/):

```sh
uvx fairway --help
```

Установить:

- через uv: `uv tool install fairway`;
- через pip: `pip install fairway`;
- через Cargo: `cargo install fairway --locked`.

Готовые пакеты для uv и pip есть для Linux x86_64 и aarch64 (glibc и musl),
macOS на Apple silicon и Intel и Windows x86_64: на этих платформах Rust
не нужен. На остальных uv и pip собирают Fairway из исходников, как
и `cargo install`. Для сборки нужен Rust 1.98.1 или новее.

Проверить установку:

```sh
fairway --version
```

## Справка

`--help` показывает справку по Fairway, пространству команд или подкоманде:

```sh
fairway --help
fairway <пространство> --help
fairway <пространство> <подкоманда> --help
```

`-h` печатает краткую справку, `--help` — полную, с подробными описаниями,
если плагин их задал.

## Коды выхода

| Код | Когда |
|---|---|
| 0 | команда выполнена, в том числе остановлена по сигналу штатно; выведена справка или версия |
| 1 | команда завершилась с ошибкой; не удалось подготовить запуск, например загрузить настройки; команда не завершилась за 15 секунд после сигнала |
| 2 | ошибка в аргументах; не указано пространство команд или подкоманда |
| 101 | внутренняя ошибка команды |

Сообщения об ошибках Fairway печатает в stderr в виде `error: ...`.

## Прерывание команды

Команду прерывают сигналы SIGINT (Ctrl+C), SIGTERM и SIGHUP на Unix
и Ctrl+C на Windows. Fairway не останавливает команду сразу: он просит её
завершиться и ждёт до 15 секунд, чтобы она успела, например, дописать
ответы и сохранить состояние. Если команда не завершилась за это время,
Fairway печатает сообщение с именем полученного сигнала и завершается
с кодом 1:

```text
error: still running 15s after SIGINT
```

Повторный сигнал срок не сокращает.

## Настройка

Настройки плагинов лежат в каталоге Fairway, по умолчанию `~/.fairway`.
Где он находится, какие файлы Fairway читает и как объединяет их значения,
описано на странице [«Настройка Fairway»](configuration.md).
